CIB seven 2.2.2 EE - Release Notes

Release Date: August 7, 2026

Highlights

  • Security Task Filter JUEL expressions can now be restricted to a safe whitelist to prevent arbitrary function/bean invocation via filter expressions (opt-in, disabled by default); postgresql JDBC driver upgraded to 42.7.12 (CVE-2026-54291); jackson upgraded to 2.21.5 and pinned in the run4 distribution and in the Tomcat AI-agent overlay (CVE-2026-59889, CVE-2026-54512, CVE-2026-54513); wildfly upgraded to 41.0.0, resolving an lz4 vulnerability (CVE-2026-59949); OpenTelemetry Java agent updated to 2.28.1 in Docker images (CVE-2026-54704, CVE-2026-54712)
  • Batch Operations (EE exclusive) New “Delete Deployments” batch operation wired into the Batch Operations wizard (define → confirm → results), and the “correlate message” operation now defaults to targeting active instances only
  • BPMN AI Agent (EE exclusive) Per-model vision flag lets a text-only model gracefully skip image/PDF attachments instead of the request being rejected
  • Start Process Default start form now supports a business key and process variables when a process definition has no configured start form
  • Modeler Released cibseven-modeler 1.2.0 and cibseven-modeler-ee 1.2.0 with further stability, accessibility, and UX fixes
  • Process Views BPMN diagram pan/zoom position is now persisted across process definition and instance views
  • Dates Webclient date fields now serialize as ISO-8601 strings instead of epoch milliseconds
  • Accessibility Additional form controls across admin, process, task filter, and tenant/deployment views now expose accessible labels

New Features

Asynchronous Deployment Deletion

  • New batch operation type deployment-deletion, exposed via POST /deployment/delete, deletes one or more deployments (by id or by query) asynchronously as a batch job
  • Supports cascade, skipCustomListeners, and skipIoMappings parameters, and merges/deduplicates explicit deployment ids with query-based selections
  • Every collected deployment is authorized individually against the DELETE permission before the batch is created
  • Documented in the OpenAPI reference

Delete Deployments Batch Operation (EE exclusive)

  • New “Delete Deployments” operation added to the Batch Operations wizard, matching the engine’s deployment-deletion batch type
  • New deployment search box and results table (query by name, source, tenant, deployment time; checkbox selection; id/name/source/deploymentTime/tenant columns), mirroring the existing batch operation table components
  • cascade, skipCustomListeners, and skipIoMappings parameters are exposed in the wizard, with the latter two shown only when cascade deletion is enabled
  • Translations added across all supported locales

BPMN AI Agent Vision Support (EE exclusive)

  • New per-model vision flag (cibseven.webclient.agent.models[].vision) lets a self-hosted or text-only model (e.g. a model pulled without a vision projector) drop image and PDF attachments with an in-line explanation instead of the provider rejecting the request
  • Defaults to true, so existing configuration keeps working unchanged
  • Documented in both the Spring Boot and WildFly application YAML

Default Start Form

  • Processes without a configured start form now get a default start form supporting a business key and process variable input

Task Filter Expression Whitelisting

  • Task Filter JUEL expressions (e.g. assigneeExpression) can now be restricted to a safe whitelist — currentUser(), currentUserGroups(), now(), a whitelisted dateTime() expression, and plain literal text — instead of being evaluated with full JUEL power
  • Whitelist enforcement applies to stored filters, adhoc task queries, and or()/endOr() query branches
  • Operators can extend the whitelist with additional exact JUEL expressions via ProcessEngineConfigurationImpl#additionalAllowedFilterExpressions, without a source change
  • Disabled by default; enable via the enableFilterExpressionWhitelist toggle

Stable Variable Instance Pagination

  • New orderByVariableId() on VariableInstanceQuery, exposed via REST as sortBy=variableId, orders results by the unique primary key for a stable pagination order
  • New streamStable() on VariableInstanceQuery and HistoricVariableInstanceQuery uses keyset (seek) pagination instead of OFFSET, so a long-running stream is not affected by concurrent inserts or deletes

Process Diagram Pan/Zoom Persistence

  • The BPMN viewer’s pan/zoom position is now persisted and restored across process definition and process instance views

User Experience Improvements in Web Client

Deployments

  • Deployment queries now support the full set of query parameters (name, source, tenant, before/after deployment time), including correct handling of null parameters and + encoding in date parameters
  • Deployment info is no longer loaded on the process definition view for users without deployment read permissions

Authorization

  • The “Delete instance” button in the process definition instances table now checks for DELETE_HISTORY permission before being shown
  • The “change password” menu item is now shown only to users with access rights to it
  • An “authorization disabled” warning banner is now shown on the Authorizations page when authorization is disabled

Process Instance Search

  • The BPMN viewer now searches only unfinished (active) process instances by default

Tasklist

  • Fixed filter task count not updating immediately after a task is completed
  • Fixed sorting descending with an active “Due date” filter returning no results

Execution Metrics

  • Annual and monthly metrics retrieval now follows the selected groupBy parameter, and all years are shown
  • Added monthly chart interaction and row click handling
  • Fixed date formatting for yearly metrics to reflect the correct date range
  • Made the historic activity statistics call backwards compatible

Multi-Engine

  • Fixed direct and default engine lookup in EngineProvider
  • Fixed redirect to the previous page instead of the start page after login during an engine switch

BPMN AI Agent Chat (EE exclusive)

  • Fixed the chat WebSocket endpoint not being registered under the webclient’s application path, causing handshake failures (404) when the webclient is served under a path prefix

Accessibility

  • Added accessible labels to admin, process view/modal/table, task filter/search, tenant/deployment, and settings form controls
  • The form-control-has-label ESLint rule is now enforced as an error for CIB form wrappers

Bug Fixes

History / “History Level None”

  • Fixed no data shown on the instance details view after a page reload when the history level is none
  • Fixed missing active-instance icon and incident indication on the instance details view when the history level is none
  • Fixed missing badges and activity filter in the BPMN viewer when the history level is none
  • History level configuration is now normalized to lowercase and handled consistently when no value is set

Variables

  • Fixed identical values shown for local variables that share a name but have different underlying values
  • Fixed historic variable history values being merged by variable name instead of by historic detail id (EE exclusive)

Modeler

  • Fixed the Modeler not destroying bpmn-js/dmn-js editor instances on tab close, causing a memory and listener leak
  • Fixed leaked global event listeners on unmount (form modal and others)
  • Fixed the element-templates store crashing on a non-array response when the Modeler backend is disabled
  • Fixed the element-template picker crashing when the picked template is not loaded in the Modeler
  • Fixed the element-template picker to only offer templates already loaded in the Modeler
  • Fixed the process definition view requesting element templates even when the Modeler is disabled
  • Fixed auto-entering a diagram when its id is present in the URL
  • Fixed save/edit-lock failures being silently dropped instead of surfaced to the user
  • Replaced the Create-new dropdown on the start page with dedicated Create BPMN/DMN/Form actions
  • Extracted a reusable resize/splitter composable for the Properties panel
  • Fixed ModelerViewEE fetching element templates from the wrong services base path (services/v1 instead of the app’s configured path), causing 404s (EE exclusive)

Forms

  • Fixed missing support for bpmnEscalation so embedded forms can report escalations
  • Fixed embedded-form SDK group/user/history calls to be served from typed middleware endpoints instead of failing against the wrong path
  • Associated the business key label with its input on the default start form

Batch Operations (EE exclusive)

  • Fixed the “correlate message” batch operation matching finished process instances; it now defaults to active instances only

Backend

  • Fixed the LDAP configurable cache introduced in 2.2.1 failing with NoClassDefFoundError because the caffeine library was not shipped in the WildFly and Tomcat distributions

Technical Updates

Dependency Updates

  • Update jackson from 2.21.4 to 2.21.5; pinned in the run4 distribution to fix CVE-2026-59889, and in the Tomcat AI-agent overlay to 2.21.4 to fix CVE-2026-54512/CVE-2026-54513; WildFly 28 Jackson modules updated to 2.22.0
  • Update wildfly from 40.0.1.Final to 41.0.0, resolving CVE-2026-59949 (lz4)
  • Update postgresql (JDBC driver) from 42.7.11 to 42.7.12, fixing CVE-2026-54291
  • Update OpenTelemetry Java agent (Docker images) to 2.28.1, fixing CVE-2026-54704 and CVE-2026-54712
  • Update cibseven-modeler to 1.2.0
  • Update cibseven-modeler-ee to 1.2.0 (EE exclusive)
  • Update cibseven-bpmn-agent to 1.0.2 to support the multimodal per-model vision API (EE exclusive)
  • Update axios from 1.15.2 to 1.18.1
  • Update bpm-sdk from 2.1.2 to 2.1.3
  • Update vite from 6.4.2 to 6.4.3 and vitest from 3.2.4 to 3.2.7
  • Update transitive dependencies dompurify (to 3.4.12), markdown-it (to 14.3.0), and fast-xml-parser (to 5.10.1) to resolve reported npm vulnerabilities
  • Resolved SonarQube security hotspots (HTTPS test fixtures, regex handling, HTML-escaping in warning banners)

Resolved CVE Vulnerabilities

High Severity

  • CVE-2026-54291 - Channel-binding downgrade vulnerability in pgjdbc, allowing an on-path attacker to bypass SCRAM channel binding on the AI agent’s PostgreSQL connector. Fixed by upgrading postgresql to 42.7.12.
  • CVE-2026-54712 - Unbounded memory allocation in the OpenTelemetry Java agent’s RMI context propagation payload reader, which limits the number of context entries but not the aggregate size of the strings read from the stream, allowing memory exhaustion via an oversized payload. Fixed in agent version 2.28.1 (lowest release clearing this alongside CVE-2026-54704).

Medium Severity

  • CVE-2026-59889 - jackson-databind @JsonView bypass in the run4 distribution, where Spring Boot 4.0.7’s BOM managed a vulnerable jackson-databind and the distro’s own Jackson pin never reached it. Fixed by importing both Jackson BOMs ahead of spring-boot-dependencies and pinning to 2.21.5.
  • CVE-2026-54704 - The OpenTelemetry Java agent’s JDBC auto-instrumentation fails to sanitize double-quoted passwords in SQL CONNECT statements, allowing clear-text database passwords to be written to trace span attributes. Fixed in agent version 2.28.1.
  • CVE-2026-59949 - Vulnerability in lz4 as bundled by WildFly. Fixed by upgrading wildfly to 41.0.0.
  • CVE-2026-54512 / CVE-2026-54513 - jackson-databind/jackson-core vulnerabilities remaining in the Tomcat distribution’s AI-agent overlay, whose lib-ai/ common loader was not governed by the distro’s Jackson version management. Fixed by pinning both to 2.21.4 and adding a Maven Enforcer guard against a silent transitive downgrade.
